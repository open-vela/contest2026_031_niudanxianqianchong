# ESP32-P4X 静态 LVGL Smart Home 首页真机验收

**日期**：2026-08-24  
**固件配置**：`board/esp32p4/esp32p4-function-ev-board/configs/smart_home`  
**阶段**：P2：无网络、无触摸的静态 LVGL 首页  
**结论**：首屏 PASS

## 1. 验收目的

在已通过的 EK79007 RGB565 `/dev/fb0` framebuffer 基线上，验证 P2 静态
Smart Home 首页能够由 LVGL 初始化、绑定 1024×600 framebuffer、完成首帧刷新并进入
定时处理循环。

该配置刻意不初始化 cAGENT、网络、模型凭据、MCP、Node gateway、App Bridge 和触摸，
因此本次结论仅覆盖本地显示链路。

## 2. 实测命令

```text
nsh> ls /dev/fb0
 /dev/fb0

nsh> smart_home
```

## 3. 串口证据

```text
=== Smart Home Static LVGL P2 ===
starting local dashboard without network, cAGENT, or touch

[lvgl-static] lv_init
[lvgl-static] framebuffer=/dev/fb0 resolution=1024x600
[lvgl-static] dashboard shown; entering timer loop
```

实板视觉确认：静态 Smart Home 首页显示正常。

## 4. 已确认范围

- board late-init 注册的 `/dev/fb0` 可被 LVGL NuttX port 打开；
- LVGL 以 1024×600 分辨率完成页面布局与首帧 flush；
- 静态首页运行在 `lv_timer_handler() + usleep()` 循环中；
- 启动日志中未出现 DNS、TLS、cAGENT、MCP、Node、密钥或触摸初始化信息。

## 5. 未覆盖项与下一步

本次未执行连续 10 分钟稳定性、重复冷启动、内存基线采集或触摸输入测试；这些保留为
P2 回归项。下一增量为 P3：接入 GT911，并先验证输入设备与 LVGL 事件分发，不同时开启
网络或完整智能体。
