## 6. 已知风险

- ESP-Hosted 在 SMP 下的 SDIO 中断路由与 WiFi 任务绑核尚未实测；若出现
  C6 枚举成功但 DHCP 超时，优先检查 SDIO IRQ 所在 CPU 与 wlan0 收包计数。
- 摄像头帧缓冲位于 PSRAM，flash 写入期间 cache 关闭可能影响 CSI DMA；
  G2 已验证双核 Flash 串行化，但摄像头与文件系统同时高负载未验证。
- miloco 持久化恢复后，运行期 LittleFS 擦除是否会再次触发 MSPI 仲裁卡死
  需要板端确认；如复现，回退到 `SMART_HOME_MILOCO_VOLATILE_CONFIG=y` 并保留日志。
- CMake 镜像尚未烧录，与 Make 镜像的运行时差异未知。
