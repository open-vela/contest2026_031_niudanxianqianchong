# 2026-10-31 V9 基准视觉审查

基准：`out/smart-home-ui-design-v9-card-layout-20261030`（43 页，最新）。
实际渲染：`docs/审查/2026-10-31-v9-baseline/`（15 张 1024×600，来自 LVGL Host framebuffer）。

色彩口径：设计用 RGB888（卡片 #F8F8F4 / 背景 #ECEFEA），Host 导出为 RGB565 再按 `*255/31`、`*255/63` 放大，同一颜色会偏 2–4 个灰阶（实测卡片 #FFFAF6、背景 #EEEEEE）。因此颜色判读只在同口径内比较，不做绝对等值。

### 显示与声音的滑块

设计两条 48 px 高滑块（亮度 80%、音量 60%），Host 是 8 px 灰轨道 + “暂不可用”。降级原因在板级：`board_mipi_dsi_backlight_set(bool)` 只有开关，源码注释写明调光属后续 PWM 集成；音量同样无控制接口。**这条不是 UI 缺陷，是能力缺口。**

### 分类行内的色块位置

Host 在 y=209–216 与 311–318 各有一条 8 px 灰条（`display_unavailable()` 的 track，y+49），设计对应位置的滑块在 y=203–226 与 305–328。轨道位置吻合，缺的是 48 px 高可交互控件。

## 五、设备弹窗：只有面板对，内容全缺

六类弹窗面板实测：设计 (93,63,838,475)，Host (93,63,838,475)——**完全一致**。摄像头弹窗设计是 898 宽（63 起），Host 仍是 838 宽，**这一处不一致**。

控件层：

| 弹窗 | 设计控件 | Host |
| --- | --- | --- |
| 吸顶灯 | 2 滑块 + 关闭灯光按钮 | 无 |

UI 主色像素统计（面板区内）：设计吸顶灯 5,726 个、风扇 968 个、洗衣机 356 个，Host 各弹窗恒为 4,432 个且全部落在 y=475–514——那是右下角 120×40 的“关闭”按钮。**弹窗内部没有任何主色控件。**

## 七、结论

**布局层基本达标**：首页卡片、设置页左右栏、底栏、顶栏、弹窗面板的坐标与设计一致（≤1 px）。
**控件层大面积缺失**：设备弹窗内部、设置页的滑块、服务页的三行按钮都还没做。
**三处明确可修**：① 首页指标区下移 6 px；② 助手气泡高度 136→94；③ 摄像头弹窗宽度 838→898。
**两处受限于板级能力**：亮度/音量滑块需要先做背光 PWM 与音量控制。
