# 首页天气图标左移（2026-11-01）

## 结论

天气图标从「贴右页边距」改为「紧随温度块右侧」，与设计稿小太阳同一水平
起始位置（x=350）。Host 回归 15/15；固件构建与烧录由使用者执行。

## 位置

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 图标 x | 872 ~ 1000 | **350 ~ 478** |
| 图标 y | 58 ~ 186 | 58 ~ 186（未变） |
| 与温度块间距 | 558px | **36px** |
| 距右页边距 | 24px | 546px |

常量 `V9_WEATHER_ICON_X` 为 350，`V9_WEATHER_ICON_Y` 与
`V9_WEATHER_ICON_PX` 未变（58 / 128）。再调位置只改 `V9_WEATHER_ICON_X`。

## 依据

设计稿 `03-devices*.png` 里温度右侧是一个 **28px 小太阳**，
alpha 包围盒 (350, 126) 28×28，与温度「28°」墨迹右边界 314 相距 36px。
实现里改成 x=350 后，128px 图标的左边界与设计稿小太阳左边界完全重合。

改前的 872 是「1024 − 24 − 128」算出来的贴右位置，导致温度右边界 314 与
图标左边界 872 之间出现 558px 空档，页头被切成互不相连的两块。

## 副作用

- **右侧留白变大**：图标右边界 478 到画布右边缘 1024 之间 546px 无内容
  （实测墨迹 0）。这是选 E 方案的必然代价，换取页头左侧的信息聚拢。
- **「演示数据」标签随图标左移**到 (350, 186) 128px 宽居中，实测墨迹
  (393, 186) 42×11，位于房间 chips（y 204）之上，不遮挡。
- **场景按钮不受影响**：(844, 206) 156×48，与图标改前改后都无重叠。

## 测试

`test_panel.c` 的天气徽标断言新增了位置检查：

    assert(lv_obj_get_x(ui->home_weather_badge) == 350);
    assert(lv_obj_get_y(ui->home_weather_badge) == 58);

同时修正两处过期注释（原文写「现为 64」「96px」，实际都是 128）。
