## 与固件实现的差异

47 张图中 **43 张与固件实现一致**，4 张屏保图仍是设计稿：

- 编号 01 的四张天气屏保（晴 / 多云 / 雨 / 夜）保存的是帆船像素壁纸方案。
  固件屏保目前使用纯色背景（`SMART_HOME_UI_COLOR_SURFACE_SOFT`），壁纸模块
  与 `res/wallpapers/` 素材均未合入。这四张图代表设计目标，不是当前实机效果。

其余页面对应的界面均已实现：见 `demos/smart_home/src/ui/lvgl/`。

## 说明

- 所有图均为 1024×600 设计稿，不含 2 倍图、SVG 源和对比图。
- 图中的天气、温度、日期、设备数量均为演示数据，不代表实机状态。
- 重新生成：设计工程位于仓外 `out/smart-home-ui-design-v10-device-service-alignment-20261101/`，
