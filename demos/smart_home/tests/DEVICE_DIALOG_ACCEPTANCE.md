# 设备控制弹窗验收

## 已接入

- 首页卡片打开 840×480 弹窗；像素插画不做平滑插值，控制区独立滚动。
- 本地灯：开关、亮度；本地空调：开关、16～30℃、五种模式、四档风速。
- 控制按稳定设备 ID 执行；同一房间的同类设备不会互相误控。
- 米家控制根据网关 spec 生成：布尔、枚举、整数范围及允许的动作。
- 范围滑块按 step 量化，松手提交；网关工作线程验证范围、枚举和在线状态。
- 属性操作需收到成功响应且实际回读符合目标，动作只标注“网关已确认动作”。
- 失败、队列满、离线和 10 秒未确认会恢复已确认值；关闭弹窗释放定时器和上下文。
- 洗衣机、扫地机器人、风扇演示模板展示控制结构，禁用真实操作；真实设备以网关能力为准。

## 可重复验证

```bash
cmake -S demos/smart_home/tests/lvgl -B /tmp/p4x-v9-main-fixes-20261031 \
  -DOPENVELA_ROOT=/home/arongw/openvela
cmake --build /tmp/p4x-v9-main-fixes-20261031 -j2
ctest --test-dir /tmp/p4x-v9-main-fixes-20261031 --output-on-failure
```

`device_dialog_check` 覆盖实际 LVGL 控件、本地按 ID 控制、整数范围解析与量化、
网关确认及回读、错误、超时、队列满、离线、动作、枚举、父页面销毁。
网关通信在主机测试中使用替身，不能代表真实米家设备已经验收。

固件采用 `smart_home` 配置编译；烧录和板端触摸、真实设备控制由用户验证。
