# V9 设备卡片素材

来源：V9 设计目录 `assets/devices` 的 160×160 透明 PNG。

生成：

```sh
python3 scripts/generate_v9_device_assets.py
```

规则：

- 每台设备先按开/关状态的可见并集裁剪一次，所有状态共用同一裁剪框和锚点。
- 采用最近邻缩放，不使用平滑缩放；卡片内以整数坐标放置。
- 输出位于本目录，供 LVGL 通过 `A:/data/res/devices/<id>-<state>.png` 读取。

| 设备 | 输出尺寸 | 卡片内位置 |
| --- | --- | --- |
| light | 103×89 | (61,143) |
| ac | 98×138 | (66,94) |
| washer | 99×114 | (65,118) |
| robot | 101×58 | (63,174) |
| camera | 92×110 | (72,122) |
| fan | 88×124 | (76,108) |

不要手工重采样或逐状态居中，否则会出现设备跳动或像素边缘发虚。
