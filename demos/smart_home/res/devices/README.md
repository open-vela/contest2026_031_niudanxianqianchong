# V9 设备卡片素材

来源：V9 设备图使用 160×160 透明 PNG。空调、洗衣机、扫地机器人和风扇来自 V9 设计目录；吊灯和摄像头采用本目录 `source/` 中保存的 Modern Semi-Flat Pixel Art 定稿。

生成：

```sh
python3 scripts/generate_v9_device_assets.py
```

规则：

- 每种设备按全部状态的可见区域并集裁剪一次，所有状态共用同一裁剪框和锚点。
- 原 V9 四种设备采用最近邻缩放，不使用平滑缩放；卡片内以整数坐标放置。
- 吊灯状态共享可见区域裁剪框；摄像头离线、在线、巡航共用裁剪框，不重采样，保持像素网格和状态锚点一致。
- 输出位于本目录，供 LVGL 通过 `A:/data/res/devices/<id>-<state>.png` 读取。
- `source/` 保存可复现的原始定稿，不会被 LittleFS 打包脚本复制到设备。

| 设备 | 输出尺寸 | 卡片内位置 |
| --- | --- | --- |
| light（吊灯） | 92×108 | (72,122) |
| ac | 98×138 | (66,94) |
| washer | 99×114 | (65,118) |
| robot | 101×58 | (63,174) |
| camera | 90×116 | (74,118) |
| fan | 88×124 | (76,108) |

不要手工重采样或逐状态居中，否则会出现设备跳动或像素边缘发虚。
